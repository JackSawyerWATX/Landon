# Hotel photography

Original Landon Hotel photography, bundled locally so deployments do not depend on the original image host or its CAPTCHA protection.

Source copy: https://github.com/edwardreyes29/landonhotel/tree/master/landonhotel.com/images/hotel

The `hotel/` directory contains 18 JPEG images used by the hero, gallery, rooms, dining, events, and neighbourhood sections.
